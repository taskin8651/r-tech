# R Tech Computer Demo QA Checklist

## Demo Logins

- Admin: `admin@admin.com` / `password`
- Student: `student@demo.com` / `password`

## Public Pages

- Home: `/`
- Courses: `/courses`
- About: `/about`
- Contact: `/contact`
- Certificate Verify: `/certificate/verify`
- Privacy: `/privacy-policy`
- Terms: `/terms-and-conditions`
- Refund: `/refund-policy`

## Admin Flow

1. Open `/admin`.
2. Check dashboard real stats.
3. Open `/admin/settings` and update phone/address/policies.
4. Open `/admin/courses` and edit a course image/content/modules.
5. Open `/admin/enquiries` and change enquiry status.
6. Open `/admin/enrollments`.
7. Edit demo enrollment.
8. Upload a certificate PDF/image.
9. Copy certificate ID and verify it on `/certificate/verify`.

## Student Flow

1. Login as `student@demo.com`.
2. Open `/student`.
3. Check My Courses tab.
4. Check Certificates tab.
5. Open certificate record.
6. If admin uploaded a file, download/open uploaded certificate.
7. Check Payment History tab.

## Final Client Content

- Replace demo phone, WhatsApp, email, address and timing from `/admin/settings`.
- Replace policy text from `/admin/settings`.
- Add real course images, fees, duration, syllabus and lessons.
- Upload real certificate files from enrollment edit page.
